# 宝塔面板部署流程（扫码挪车 PHP 版）

> 全程约 10 分钟。按步骤做即可，**第 4 步「运行目录设为 public」和第 5 步「伪静态」是唯一容易踩坑的地方**，请照抄。

---

## 0. 准备材料

- 一台国内服务器（1 核 2G 起，带宽 1M 即可）
- 一个已解析到该服务器 IP 的域名
- 宝塔面板已安装（[官网](https://www.bt.cn/)）

---

## 1. 安装运行环境（软件商店）

进入 **宝塔面板 → 软件商店**，安装以下三项（都已装则跳过）：

| 软件 | 版本建议 |
| --- | --- |
| Nginx | 1.20+（或 Apache 2.4） |
| MySQL | 5.7 或 8.0（MariaDB 亦可） |
| PHP | **7.4 / 8.0 / 8.1 / 8.2 任一**（推荐 8.0+） |

> 小站点直接用 SQLite 可不装 MySQL，安装向导里选 SQLite 即可。

---

## 2. PHP 安装扩展 + 调整配置

**软件商店 → 已安装 → PHP-8.x → 安装扩展**，勾选确认已安装：

- ✅ `pdo_mysql`（用 MySQL 必装）
- ✅ `pdo_sqlite` / `sqlite3`（用 SQLite 必装）
- ✅ `mbstring`
- ✅ `openssl`
- ⭕ `gd`（可选：新版二维码默认输出 SVG，不依赖 GD；装了才能用 `&format=png`）
- ✅ `curl`（**发短信/企微/微信通知必需**）

**配置修改（同一页面的「配置文件」）：**

```ini
upload_max_filesize = 20M     ; 导入 CSV 需要
post_max_size = 20M
max_execution_time = 60
memory_limit = 128M
```

**禁用函数**：默认禁用的 `putenv` `proc_open` `shell_exec` 等**不影响**本系统，无需解除。改完记得点「保存」并重载 PHP。

---

## 3. 创建站点 + 数据库

### 3.1 建站

**网站 → 添加站点**，填写：

- 域名：`car.你的域名.com`（按需）
- 数据库：选 **MySQL**，字符集 **utf8mb4**（宝塔会自动建库建账号）
- PHP 版本：选刚装的那个
- 其他默认，**先不要勾选**「防跨站攻击(open_basedir)」之外的奇奇怪怪选项

记下自动生成的**数据库名 / 用户名 / 密码**（在「数据库」页可随时查看，后面安装向导要用）。

### 3.2 上传源码

三种方式任选其一：

**方式 A：Git 拉取（推荐，方便后续升级）**
```bash
cd /www/wwwroot/car.你的域名.com
git clone https://github.com/lzk898482768/move-car-php.git .
```

**方式 B：宝塔文件管理上传 zip**
把仓库打包成 zip → 宝塔「文件」进入站点根目录 → 上传 → 右键解压到当前目录 → **确认解压后 `public`、`app`、`storage` 直接在根目录**（不要多一层 `move-car-php/`）。

**方式 C：宝塔「远程下载」**
文件 → 远程下载，URL 填 `https://github.com/lzk898482768/move-car-php/archive/refs/heads/main.zip`，下载后解压到站点根目录。

---

## 4. 设置运行目录为 public（关键！）

**网站 → 设置 → 网站目录**：

- **运行目录**：改为 `/public`
- **防跨站攻击(open_basedir)**：**勾选开启**（这样 PHP 只能访问 `public/`，更安全）

> ⚠️ 不做这一步的后果：任何人都能直接访问 `你的域名/app/config.php` 下载到加密密钥；且 `/install.php` 路径不对。

如果宝塔版本没有「运行目录」选项，改用 **根目录部署 + 伪静态指向 public**：
```nginx
location / {
    try_files $uri $uri/ /public/index.php?$query_string;
}
```
同时务必在「配置文件」里加：
```nginx
location ~ ^/(app|storage)/ { deny all; }
```

---

## 5. 配置伪静态

**网站 → 设置 → 伪静态**，粘贴下面内容并保存（PHP 版本号按实际改）：

```nginx
location / {
    try_files $uri $uri/ /index.php?$query_string;
}

# 静态资源缓存
location ~* \.(?:css|js|png|jpg|jpeg|gif|ico|svg|webp|woff2?)$ {
    expires 7d;
    access_log off;
    add_header Cache-Control "public";
}

# 二维码接口缓存 1 天
location = /qr.php {
    add_header Cache-Control "public, max-age=86400";
}
```

完整版（含 PHP 解析段）见 [docs/nginx.conf](nginx.conf)。

> **Apache 用户**：仓库已自带 `public/.htaccess`，开启伪静态即可，无需手动配置。

---

## 6. 设置目录权限

**文件 → 进入站点根目录 → 右键 `storage` → 权限**：设为 `755`，所有者 `www`（宝塔默认即是）。
`storage/cache` 与 `storage/logs` 需**可写**。

命令行版本：
```bash
cd /www/wwwroot/car.你的域名.com
chown -R www:www .
chmod -R 755 storage
```

---

## 7. 运行安装向导

浏览器打开 **<https://你的域名/install.php>**，填写：

| 字段 | 填写内容 |
| --- | --- |
| 数据库类型 | `MySQL`（小站点可选 `SQLite`） |
| 数据库主机 | `127.0.0.1`（默认即可，用 localhost 若报 socket 错就改回 127.0.0.1） |
| 端口 | `3306` |
| 数据库名 | 第 3 步宝塔生成的库名 |
| 用户名 / 密码 | 第 3 步生成的**数据库账号**（不是面板账号） |
| 超管账号 | 如 `admin` |
| 超管密码 | **至少 8 位**，建议字母+数字+符号 |

点「开始安装」→ 出现 **安装已完成 ✅** 即成功。向导会自动：建表建索引、生成 AES 密钥、创建超管账号、写入 `app/config.php`。

---

## 8. 安装后收尾（安全建议）

1. **删除或改名安装入口**（防止被重装覆盖数据）：
   ```bash
   mv /www/wwwroot/car.你的域名.com/public/install.php \
      /www/wwwroot/car.你的域名.com/public/install.php.bak
   ```
   以后要重装再改回来。

2. **申请 SSL**：网站 → SSL → Let's Encrypt → 申请 → 开启「强制 HTTPS」。
   > 不开启 HTTPS，手机上「点击拨号/一键通知」在部分浏览器会被拦截。

3. **备份**：宝塔 → 计划任务 → 添加「备份数据库」每日一次 + 「备份网站」每周一次。
   `app/config.php` 里的密钥要跟着一起备份，否则换了密钥旧数据解不开。

## 9. 开始使用

| 入口 | 地址 | 说明 |
| --- | --- | --- |
| 首页（创建挪车码） | `/` | 车主录入车牌 + 手机号，生成挪车码 |
| 访客挪车页 | `/move.html?c=<码串>` | 扫码进入；未绑定的码会提示车主先绑定 |
| 车主后台 | `/owner.html` | 管理密码找回入口 |
| 超管后台 | `/admin.html` | 用第 7 步的账号登录 |

**后台配置通知渠道**（超管后台 → 通知渠道）：
- 企业微信机器人：填 Webhook 地址
- 微信公众号：填 AppID / AppSecret / 模板ID / 收件人 OpenID
- 短信：选服务商（腾讯/阿里/自定义）并填密钥、签名、模板ID
- 隐私号：选服务商并填接口参数
- **只有「开关打开 + 参数齐全」的通道才会显示在前台**，缺参数时后台会标「缺参数」

## 10. 故障排查

| 现象 | 原因 / 解决 |
| --- | --- |
| 打开首页跳到 install 或直接报「未安装」 | `app/config.php` 未生成或 `storage/` 不可写 → 重跑安装向导，检查权限 |
| 安装页 500 | PHP 缺 `pdo_mysql`/`pdo_sqlite`；或数据库账号密码错误（面板「数据库」页可重置） |
| 二维码不显示 | 新版默认 SVG 无需 GD；确认 `qr.php?text=test` 直接访问能返回 `image/svg+xml` |
| 通知发不出去 | PHP 没装 `curl`；或通道参数不全（后台看是否有「缺参数」标记） |
| 页面 404 | 伪静态没配置，或运行目录不是 `public` |
| 后台一直提示登录失效 | 站点换了域名导致 `storage` 会话目录权限异常 → 检查 `storage` 属主为 `www` |
| 导入 CSV 中文乱码 | 用 UTF-8 编码保存 CSV（Excel 另存时选「CSV UTF-8」） |

---

## 11. 升级

若用 Git 部署：
```bash
cd /www/wwwroot/car.你的域名.com
git pull
```
不会覆盖已存在的 `app/config.php`（已在 .gitignore 中），数据库结构会自动增量补齐。

手动部署：下载新版本 zip，覆盖 `app/` 与 `public/`（**保留 `app/config.php` 与 `storage/`**）。
